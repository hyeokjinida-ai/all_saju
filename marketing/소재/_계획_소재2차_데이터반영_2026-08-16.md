## 3. 만들 소재 2본 — 위닝 공식 그대로

### 소재 A · **9초** — WIN2 공식 (TIGHT, 재집행 36회, 노출 6위)
WIN2 구조: *훅 한 문장을 3컷 동안 유지하며 배경만 바꾼다 → 캐릭터 → 로고 → CTA*

```
[상단 2줄 고정 — 9초 내내 안 내린다]
        네가 만날 사람,
        얼굴부터 봐라

0.0–1.2  gate.mp4     신당 입구로 들어감          ┐
1.2–2.4  altar.mp4    제단·촛불                   ├ 훅 그대로 유지(3컷)
2.4–3.6  face.webp    갓 그림자 정면              ┘
3.6–5.2  ★ 결과지 「네 운명의 상대」 카드 실물 — 얼굴 + 항목
5.2–6.6  ★ 얼굴 카드 클로즈업 (첫인상 / 만나는 자리 / 나이대)
6.6–7.6  명운록 命運錄 인장
7.6–9.0  [무료로 먼저 보기]  버튼
```
- **결과지 실물 노출**(12/14) + **상대 얼굴**(1등 훅) + **상단 훅 고정**(9/14) 세 장치를 한 번에 태운다
- 판매 가격 없음. 「무료로 먼저 보기」만 — 우리 퍼널이 실제로 무료 티저다

### 소재 B · **20초** — WIN3 공식 (귀신사주, 재집행 29회)
WIN3 구조: *정지 사진 4~5장 + 자막. **20초 내내 판매 문구 0.** 마지막 3초에 버튼 하나*

```
0–3    close.webp    「이상하다.」
3–6    altar.webp    「명운록 서고엔 장부가 있다.」
6–9    ganji.webp    「사람마다, 여덟 글자로 적힌 장부.」
9–12   stand.webp    「산군은 그걸 먼저 읽는다.」
12–15  t3-snap.webp  「좋은 말만 해주지는 않는다더군.」
15–17  face.webp     「네 장부엔 뭐라 적혀 있을까.」
17–20  [산군에게 장부 받기 >]
```
- 제작비 0, 판매 문구 0. **괴담만 한다** — 귀신사주가 이걸로 29회 돌린다
- 산군 어투(`~다`/`~라`) 유지

### 규격
각 소재를 **9:16(1080×1920)** + **4:5(1080×1350)** 두 벌. 총 **4개 mp4**.
1차 정지컷 4장은 삭제하지 않고 **이미지 예비**로 남긴다(메타가 이미지 슬롯도 요구할 때 씀).

## 4. 제작 파이프라인 — 형님 품 0

제품 저장소를 오염시키지 않기 위해 **`marketing/tools/` 에 별도 `package.json`**을 둔다(제품 빌드와 완전 분리).

| # | 도구 | 용도 |
|---|---|---|
| 1 | `puppeteer` (devDep, tools 전용) | headless Chrome 으로 `/dev/sangun-result` 의 **결과지·얼굴 카드 실물을 PNG 로 캡처**. 지금 Browser pane 스크린샷이 파일로 안 떨어지는 문제를 이걸로 뚫는다 |
| 2 | `ffmpeg-static` (devDep) | 클립 concat · 자막 번인 · 비율 크롭 · mp4 인코딩 |
| 3 | Pillow (이미 있음) | 자막 프레임·상단 훅 밴드·CTA 카드 합성 |

실행: `node marketing/tools/build-ads.mjs` → `marketing/소재/산군/` 에 mp4 4개.
스토리보드는 그 스크립트 안 **선언형 배열**로 둔다 — 컷 한 줄만 고치면 다시 뽑힌다(#74 「이긴 걸 복제」 대비).

⚠ 설치 용량 ~260MB(node_modules 안, 시스템 오염 없음). 다운로드 실패 시 대안:
정지컷 시퀀스만 Pillow 로 만들고 **`ffmpeg-static` 만** 설치해 인코딩(= 소재 B 는 그대로 가능, 소재 A 는 결과지 캡처를 형님 스크린샷 1장으로 대체 요청).

## 6. 판정선 (1차 카피시트와 동일, 소재만 교체)

| 상황 | 판정 |
|---|---|
| 30만 소진 · ROAS < 0.8 | 훅 교체 (상단 2줄만) |
| **ROAS 1.5+** | 위닝 → **광고 6~10개로 복제해 물량**(#74). 새로 찍지 않는다 |
| CTR < 0.6% | 첫 3컷(훅 구간) 교체 |
| 클릭은 나오는데 CVR < 0.5% | 소재 아님 → 티저 결함 |
