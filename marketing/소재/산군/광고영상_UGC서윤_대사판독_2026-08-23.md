# 서윤 무성 UGC + TTS 광고 — GPT 대본 판독 (2026-08-23)

형님이 GPT와 짠 「사주 보러 들어갔다가 내 인생 패턴 들킴」 47초 대본을 **실제 산군 결과지(11장)·위닝 실측 상수(v4 §1-2)**에 대조한 기록.
제작 도구 = Seedance(서윤 무성 연기) + CapCut(TTS·자막·카드). 결론부터: **뼈대는 채택, 대사는 절반 손본다.**

## 1. 기능 대조 — 실제 산군 결과지에 있는 것만 광고한다

| GPT 대본 주장 | 실제 | 처리 |
|---|---|---|
| 타고난 성향 | ✅ 1장 「네 그릇부터 보자」 — 본바탕·강점 2·**남들과 다른 결 1**(형광 문장 `==…==`) | 카드 = 1장 형광 문장 실캡처 |
| 연애 패턴(「끝난 거 알면서 붙잡는 타입」) | ⚠ 산군에 「연애 패턴」 장은 없음(직녀 3장에 있음). 대신 **9장 「네 물음에 답한다」**가 고민 입력에 직언으로 답함 | 서윤 고민 입력 = 「헤어진 사람한테 연락하고 싶다」 → 9장 직언 실캡처(vS 대본 「네 뒤에 서 있는 건 사람이 아니라 미련이다」 결) |
| 돈 버는 방식 | ⚠ 「월급형/사업형」은 재물 상품. 산군 4장은 **재물그릇 점수 + 돈 드는 달·새는 달 + 직언 3** | 목차 플립에 「돈이 들어오는 달」로 노출(연·월 열 제거) |
| 직업 성향 | ⚠ 6장 「일과 자리의 시기」= 이직·계약 타이밍 | 목차에 「일」로만 |
| 인간관계 / 올해 흐름 | ✅ 3장 「올해 네게 오는 것, 떠나는 것」 · 7장 「조심할 달」 | 목차 플립 |
| 다음 상대 — 외모/성격/**직업**/관계 스타일 + 남성 이미지 | ✅ 5장 **PartnerCard**: 얼굴 사진(오행×성별 10장 고정, `partner-m-*.webp`) + **외모 / 성격 / 만나는 자리** + 본문 나이대·관계 흐름. **직업 ✗**(단정 금지) | 카드 항목 = 외모·성격·만나는 자리. 티저가 블러로 예고 → 결과지 해제 = 광고에서도 **블러→해제 1.75s** |
| 2026→2029 연도 그래프 | ⚠ 연도별 그래프 UI 없음. 있는 건 **2장 「네 대운 연대기」 표**(10년 단위 나이 구간·간지·한 줄 「바람이 등 뒤에서 분다」·**지금** 배지) + 8장 「크게 바뀌는 해」 | 대운표 실캡처, **연도 열 숨김(나이만)** — v4 §7 검문 「미래 연·월 자막 0건」 그대로. 「10년 단위」가 「인생 패턴」에 더 맞는 그림 |
| 「친구들 거까지 보는 중」 | ✗ 건당 유료. 무료는 티저 몇 줄 | 「생년월일만 넣으면 몇 줄은 무료」로 교체(카피시트 허용 문구) |

카드 문장은 **실화면**이어야 한다(v4 채택: 「*실제 사주 서비스 화면입니다」 상시). → 서윤 생년월일을 정해 진짜 결과지를 굽고 거기서 캡처한다. 기본값 **1994-06-06**(v4 타이핑 스텝과 같은 값) + 고민 「헤어진 사람」.

## 3. 서윤 Seedance 컷 — 3클립(15s×3), 무성

| 클립 | 구간 | 동작 명령(타임스탬프 박아서) |
|---|---|---|
| A | 0–15 | 침대 헤드에 기대 폰을 대충 훑다 **2.0s 멈춤** → 눈썹 살짝 → **4.5s 피식 + 렌즈 0.5s** → 폰으로 복귀 → 8s부터 상체 앞으로 당김 → 13s 끄덕 2회 |
| B | 15–30 | 읽다 **멈춤**(17s) → 입술 깨묾 → **렌즈 0.5s → 폰**(20s) → 23s 「아…」 입모양 + 피식 → 28s 폰을 얼굴 가까이, 눈 커짐, 두 손가락 확대 |
| C | 30–48 | 피식(33s) → 헤드에 기대 천천히 스크롤 → **한 줄에서 멈춤 3s**(38s) → 피식(44s) → 끝까지 폰만 봄, 렌즈 X |

- 공통: `Locked-off static camera` · `no speech, mouth closed except a small laugh` · 눈 깜빡임 3~4s · 머리카락 몇 가닥 · 폰 든 손가락 미세 조정 · `No UI or text on the phone screen`(크로마 대신 **폰 화면은 어둡게**, 카드는 CapCut에서 얹음)
- 이음매 15s·30s = **카드 교체 순간**에 겹쳐 컷(v4 U2 규칙). 동일인 실패 시 출구: 2클립(0–30)판 = 35초 컷
- 서윤 정지컷: **침실·저녁 스탠드 조명·헤드에 기대 폰**(K3 슬롯) — ChatGPT 웹 1장, 0cr. 프롬프트 블록은 `재료/UGC/프롬프트_한국인플루언서톤.md` [한국인 얼굴 블록] 그대로
- 크레딧 ≈ 405cr(3클립) + 재시도 예비 270 = **≤ 675cr**(v4 1차 850과 별도)

## 5. 레퍼런스 분석본 대조 (형님 추가 제공 · 같은 날 밤) — §0 판정 2개 수정

레퍼런스 = 47.7s 뷰티 인플루언서 + **빠른 남성 AI TTS** + 자미두수(「평생사주 자미두수」 웹툰 캐릭터 타이틀). 아카이브 대조: 「자미두수 미쳤네 / 밤하늘의 별로 운명을 읽어주는 몽월소녀」 = **꿀팁저장소**(콘텐츠형 페이지, 소재 ~10개, 점유 1.5%, 업체랭킹 6~9위)로 추정. **재집행 수치 없음 → 구조는 빌리되 '검증된 위닝'은 아니다.** mp4는 아카이브에 없음(파일 오면 `frames.py` 0.25초 해부).

### 5-1. 철회 — TTS 속도
| | 음절 | 초 | 음절/초 |
|---|---|---|---|
| 레퍼런스 대사(분석본 그대로) | 334 | 45.2 | **7.4** (최고 구간 8.0) |
| GPT 원안 | 322 | 47 | 6.85 |
| v2(§2) | 258 | 48 | 5.4 |
| **v3(§6)** | 318 | 48 | **6.6** |

§0의 「64초 분량」 판정은 **자연 낭독 기준이라 이 장르엔 틀렸다.** 레퍼런스·위닝 체험형(U2 자막 1.5~1.7s/줄 ≈ 6~7/초) 모두 빠른 TTS(1.2x)로 돈다. 남는 문제는 **35~41 한 구간뿐**(71음절/6초 = 11.8/초, 레퍼런스 최고 8.0) → 8초로 늘리거나 20음절 덜면 끝. v2는 「느린 판」(자막 가독 변형)으로 강등, **본판 = v3**.

### 5-2. 수정 — 남성 TTS
레퍼런스가 여자 1인칭(「나 어릴 때부터 어른 같다는 말」)을 남성 TTS로 읽는다 = **장르 관습, 가능.** 단 레퍼런스 인물은 렌즈 보고 검지 치켜세우고 👇 찌르는 **'프레젠터 더빙' 구조**다. 서윤은 말도 손짓도 없이 침대에서 읽기만 → 목소리가 '속마음'이 돼 성별이 튄다. 출구 둘: ①여성 1인칭(기본값 유지) ②남성으로 가려면 서윤에게 **렌즈 향한 제스처 2개**(0:00 폰 가리키기 · 0:44 👇)를 넣어 더빙 구조로 바꾼다(0cr, 프롬프트 한 줄).

### 5-3. 레퍼런스가 확인해 준 것 → 대본에 넣은 것
| 레퍼런스 장치 | 비중 | 우리 치환 |
