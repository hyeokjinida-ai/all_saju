## 6. 남은 것

- **4:5 완성본 3편은 일부러 안 뽑았다** — 형님이 TTS·자막을 직접 갈 수 있다고 해서, 내 자막으로 4:5 를 더 뽑는 건 버려질 일이 된다.
  편집용 무음판은 9:16·4:5 둘 다 만든다. 형님이 「지금 자막 그대로 간다」 하시면 그때 `build_seoyun.py all --ratios 4x5` 한 줄이면 나온다(약 45분).
- 형님 확인: ① 폰으로 본판 1회 시청 ② 훅 3개 중 1차 투입 픽(기본값 = V0·V2·V3 전부) ③ 목소리(Talia) 유지 여부 ④ 편집용 무음판에서 **카드·크로마도 뺄지**(지금은 남겨 뒀다 — 다시 만들기 번거로운 뼈대라서)
- ⚠ **제품 결함 1건**(광고와 별개): 짝 카드 「만나는 자리」에 공급사 경고문(「이미 기혼자와…」)이 장소로 들어온다.
  광고는 그 행 **위에서 잘라** 우회했다(`seo_partner_card_ad.png`). 제품은 미수정 — `placeFromHint()` 거절 목록 필요.

### 밟은 함정 (다음에 반복 금지)
1. **`Page.navigate` 무응답** — about:blank 에서 찍혀 백지 + scrollHeight=뷰포트. 조용히 실패한다. → 패치 완료.
2. **결과지 페이지 높이가 실행마다 다르다**(23,883 / 24,299 / 29,705 css px). 좌표와 픽셀이 다른 실행에서 나오면 전부 어긋난다 → **창마다 rects 를 같이 받는다.**
3. **텍스트 검색이 RSC `<script>` 페이로드를 집는다**(0×0 rect). → 보이는 요소만.
4. **`<mark>` rect 로 자르면 위아래 줄이 반쯤 들어온다**(폭으로는 문단과 구별 안 됨 — 326 vs 332). → 인라인을 벗어날 때까지 올라가거나, 줄 경계 그대로 쓰려면 여백 0.
5. **seed_audio 한국어 한계** — 「장부」·「각오」·「까는데」가 뭉갠다. speech_rate 100 은 문장이 무너지고 **75가 상한**.
