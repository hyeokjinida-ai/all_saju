# 편집용 v6 — 자막·TTS 를 형님이 직접 갈아끼우는 세트 (2026-08-24)

완성본은 한 층 위 `영상/` 에 있다. 여기 있는 건 **캡컷에서 손대기 좋게 벗겨 놓은 판**이다.

## 무엇이 들어 있나

| 폴더 | 소재 | 길이 |
|---|---|---|
| `vK/` | 과거검증 드라마 (서윤) | 28.0s |
| `vC2/` | 설화 「~단다」 (산군 루프) | 20.0s |
| `vA2/` | 얼굴 4컷 | 9.0s |

각 폴더 안:

| 파일 | 소리 | 자막 | 훅 | 언제 쓰나 |
|---|---|---|---|---|
| `vK/*_noSub.mp4` | **O**(TTS) | ✗ | **O** | vK 자막만 다시 얹을 때 |
| `vK/*_clean.mp4` | ✗ | ✗ | ✗ | vK 를 통째로 새로 얹을 때 |
| `vC2/*_clean.mp4` | ✗(원래 무음) | ✗ | ✗ | vC2 글자를 새로 얹을 때 |
| `vA2/*_noText.mp4` | **O**(앰비언스) | ✗ | ✗ | vA2 글자를 새로 얹을 때 |
| `*_자막.srt` | — | 타임코드 자막 | — | 캡컷 임포트 그대로 |
| `*_대본.txt` | — | 초 단위 표 + 연출 메모 | — | 문장을 고칠 때 |
| `vK/vK_나레이션_믹스.wav` | 28초 통짜 TTS(룸톤 포함) | | | 소리만 쓸 때 |
| `vK/나레이션_낱개/line_01..07.wav` | 문장별 원본 + Whisper 대조 | | | 한 줄만 갈아끼울 때 |

⚠ **vK 만 `_noSub` / `_clean` 이 갈린다.** vK 는 훅이 자막과 별개 레이어라 「훅은 두고 자막만」이 되지만,
**vC2·vA2 는 훅과 자막이 한 덩어리**라 글자를 빼면 전부 빠진다. 그래서 이름을 다르게 뒀다
(vA2 는 소리가 남아 있어 `_clean` 이 아니라 `_noText`).

⚠ **훅은 자막이 아니라 소재의 뼈대다** — 위닝 6편이 전부 상단 훅을 통으로 고정한다.
다시 얹을 때 훅을 빼면 공식이 깨진다. 훅 문구는 각 `_대본.txt` 머리에 적어 뒀다.

## 다시 뽑는 법

    PYTHONUTF8=1 python marketing/tools/export_subs.py                                  # srt·대본만
    PYTHONUTF8=1 python marketing/tools/build_vk.py NOSUB CLEAN --ratios 9x16,4x5        # vK 영상
    PYTHONUTF8=1 python marketing/tools/build_ads.py vC2_seolhwa vA2_face --ratios 9x16,4x5 --notext

`export_subs.py` 는 **빌더의 대본 상수를 그대로 읽는다** — 자막을 따로 손으로 적지 않으므로 영상과 어긋날 수 없다.

## 갈아끼울 때 지켜야 할 것

### vK (28s)
1. **과거를 두 번 짚고 나서 「이걸 어떻게 알지?」** — 2·3번 줄 → 13.7s 정점. 이 순서가 이 소재의 전부다(W4 공식).
2. 얼굴 카드(16.8~20.7s)는 **블러를 풀지 않는다.** 궁금증을 잠근 채 끝내는 게 W4 의 마지막 장치다.
3. **끝에 CTA 를 붙이지 않는다**(K0 기준). 붙인 판이 필요하면 `sangun_vK_KE_*` 가 이미 있다.
4. 다른 TTS 로 갈 때 **「장부」·「각오」는 피한다** — seed_audio 가 뭉갠다(v5 실측). 지금 대본엔 이미 없다.
5. 연·월 숫자는 **카드 안에서만** 보이게 한다. 자막·음성에 넣으면 개인화 없는 단정이 된다.

### vC2 (20s)
1. 어미는 **「~단다」**. 「~라고 해」는 귀신사주가 135건으로 도배한 어미라 아류로 읽힌다.
2. 강조는 **형광 배경 + 흰 글씨**. 색 글씨로 하면 촛불 배경에 묻힌다(2번 실패하고 알았다).
3. **CTA 구간이 5.6초(28%)** 다. 짧게 줄이면 W2 공식이 깨진다.
4. 판매 문구·가격·특정 월은 넣지 않는다.

### vA2 (9s)
1. **컷은 4개까지.** 잘게 쪼개면 W3 대비 산만해진다(1.29초/컷으로 만들었다가 되돌린 이력).
2. **3.1~5.7s 카드 구간은 무자막이 맞다** — 카드 본문과 겹치면 둘 다 안 읽힌다.
3. 엔딩 2.2초(24%)를 줄이지 않는다.

## 화면 문구 정책 (전 편 공통)
- 화면 안 **가격·「구매」·링크 0** — 재사용 상위 위닝이 전부 그렇다.
- 결과지가 보이는 소재엔 **「\* 예시 결과 · ○○년생 표본」** 라벨을 상시 노출한다.
- 개인화 없는 소재에서 **연도·달을 단정하지 않는다**(카드 실물은 예외 — 손님 결과지 화면이므로).
