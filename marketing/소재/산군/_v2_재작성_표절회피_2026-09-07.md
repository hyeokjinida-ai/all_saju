# 인스타툰 전편 재작성 v2 — 레퍼런스와 거리 벌리기 (2026-09-07)

형님 지적: 「재물툰 너무 베낀 것 같다. 캐릭터는 다르지만 구도·멘트·위치까지 비슷하다.」
GPT 판정 요청(대화 `6a9dabd9`) → **10컷 중 6컷 「사실상 복제」, 2컷 「위험」, 2컷만 안전**.
클로드 대조도 같은 결과. **v1 전편을 폐기하고 다시 짰다.**

## 0. 무엇이 문제였나 (컷별 판정, GPT + 클로드 일치)
| 컷 | 판정 | 겹친 것 |
|---|---|---|
| 1 | 사실상 복제 | 「A 포기했던 내가 [나이]에 B한 썰」 + 「(○○ 딱 한 번 본 게 다임)」 골격 |
| 3 | 사실상 복제 | 「~ㅋㅋ」 + 「이러다 ○○하는 거 아냐?」 리듬 |
| 4 | 사실상 복제 | 「그러다 ~ 사주 얘길 꺼냄」 + **카페 2인 대화** 장면 |
| 5 | 사실상 복제 | 「**속는 셈 치고**」 + 혼자 폰으로 열어보는 장면, 같은 위치 |
| 6 | 사실상 복제 | 폰으로 결과 보고 「소름」 반응 컷 |
| 10 | 사실상 복제 | 「너네도 해보라고 링크 가져왔음」 + **쿠폰 들고 아래 가리키는 장면** |
| 2·8 | 위험 | 기능과 배치가 같음 |

★ **가장 큰 것은 문장이 아니라 순서였다** — 「현재 문제 → 불안 → 지인이 추천 → 반신반의 → 소름 → 현실 적중 → 링크」.
문장만 고치고 이 뼈대를 두면 원작자가 알아본다.

## 1. 골격을 꺾었다
| | v1 (폐기) | **v2 (지금)** |
|---|---|---|
| 발단 | 남이 사주를 꺼낸다 | **내가 먼저 이상함을 느낀다**(영수증·기록부터 뒤진다) |
| 검증 | 예언이 현실에서 맞는다 | **내 지난 기록과 대조한다** |
| 반응 | 소름 | 겹쳤다 · 표시해 둔다 |
| 결말 | 예언 성취 | **미리 알고 대비했다** |
| CTA | 캐릭터가 쿠폰 들고 아래 가리킴 | **결과지 실물 캡처**(위닝 14개 중 12개가 결과 화면을 띄운다) |

## 2. 버린 문장·장면 (전편에서 제거 확인)
「속는 셈 치고」 · 「너네도 해보라고 링크 가져왔음」 · 「그러다 ~ 얘길 꺼냄」 · 「이러다 ~ 아냐?」 ·
「포기했던 내가 [나이]에 ~한 썰」 · 「소름 돋아서」 · **카페에서 사주 꺼내는 컷** · **쿠폰 들고 가리키는 CTA 컷**

## 3. 유지한 것 (장르 공유 재산 — GPT 판정)
「~썰」 제목 형식 · 1인칭 경험담 · ㅋㅋ·구어체 · 핵심어 색 박스 · 상단 내레이션+하단 속마음 · 폰 보는 장면.
단 **「~썰」의 앞부분 공식**은 바꿨다: 「돈이 안 남아서 석 달치 카드값을 뒤져본 썰」.

## 4. v2 여섯 편
| 폴더 | 컷 | 축 | 표지 |
|---|---:|---|---|
| `이미지툰_v2_A_재물_손그림` | 9 | 재물 | 돈이 안 남아서 / 석 달치 카드값을 뒤져본 썰 |
| `이미지툰_v2_B_재물_컬러` | 9 | 재물(A와 같은 대본, 톤 A/B) | 〃 |
| `이미지툰_v2_C_과거` | 8 | 증명 | 사주 안 믿다가 / 기록부터 맞춰본 썰 |
| `이미지툰_v2_D_얼굴` | 8 | 상대 얼굴 | 연애 접고 살다가 / 짝 카드를 본 썰 |
| `이미지툰_v2_E_직언` | 8 | 부정 판정 | 듣기 싫은 말만 해서 / 껐다가 다시 켠 썰 |
| `이미지툰_v2_F_취준생` | 8 | 합격 시기 | 스무 번 미끄러지고 / 시기부터 본 썰 |

각 편 마지막 컷의 결과지 캡처는 **축에 맞춰 다르게** 넣었다 — 재물=돈의 달력, 과거·취준생=직언 줄과 대운 연대기, 얼굴=짝 카드.

## 5. 남은 위험 (정직하게)
- **취준생 3컷에 카페 2인 장면이 남아 있다.** 사건은 다르지만(친구 합격 소식) 장면은 겹친다. GPT는 카페 2인 자체는 공유 재산으로 봤다. 더 멀리 가려면 이 컷도 교체한다.
- 「봐주는 게 갓 쓴 박수무당인데 / 얼굴이 없음;;」은 전편에 반복된다. 원작에 없는 우리 것이지만 **여섯 편에서 같은 문장을 쓰면 우리 안에서 물린다.** 2라운드에 변주가 필요하다.
- GPT는 우리 그림을 못 봤다. **그림 대조는 내가 했고**, 카페·쿠폰 두 컷이 겹쳐서 제거했다.
