# 직녀 에셋 슬롯 — 여기에 파일만 넣으면 켜집니다

**코드는 안 건드려도 됩니다.** 아래 이름으로 이 폴더에 저장하고 `/jiknyeo` 새로고침하면 그 자리가 채워집니다.
아직 안 넣은 자리는 라벨이 찍힌 달빛 패널로 남아 있어서, 몇 장만 넣어도 페이지는 계속 성립합니다.

## 규칙 세 줄

- `<id>.webp` (또는 `.png` / `.jpg`) → 그 컷이 **이미지**로 뜹니다
- 같은 이름의 `<id>.mp4` 를 같이 넣으면 → **영상으로 자동 승격**됩니다(webp 는 포스터로 남습니다)
  - ⚠ **영상만 넣으면 안 됩니다.** 포스터가 없으면 영상을 못 틀 때 빈 칸이 되므로, `.mp4` 를 쓸 거면 같은 이름의 `.webp` 를 **반드시 같이** 넣어 주세요
- 권장 규격 **1024×1536 (세로 2:3)** · 영상은 5초 안팎 무음 루프
