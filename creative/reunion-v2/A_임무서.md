# A · 임무서 — 재회 레인 Creative Director

> 기준일 2026-09-05 · 브랜치 `jiknyeo-reunion` · 이 팩은 **읽기 전용 정리 문서**다.
> 이 문서를 포함해 팩 전체는 코드·자산을 한 줄도 바꾸지 않았다.

## 1. 당신이 맡은 것

상품 **「견우의 재회예보」**(slug `reunion-saju`) 하나다. 다른 상품(박수무당 사주·직녀의 연애예보)은 배경 지식일 뿐 이번 임무 대상이 아니다.

이 상품은 **이미 만들어져 있다.** 랜딩·입력 6문항·티저 아홉 컷·결과지 10장·표본 결과지 2건까지 서 있고, 아직 **공개 전**이다(운영 DB에 상품 행이 없다). 그래서 당신이 할 일은 백지 기획이 아니라 **「지금 것을 사고 싶게 만드는 델타」**다.

목표 한 줄: **새벽 2시에 이 페이지를 연 32살 서윤이, 끝까지 읽고 결제하게 만든다.**

## 2. 읽는 순서

| 절 | 문서 | 이걸로 아는 것 |
|---|---|---|
| A | 이 문서 | 임무·규칙·출력 규격 |
| **B** | **현행 재고표** | **지금 화면에 실제로 뜨는 것 전부.** 가장 중요 |
| C | 우리 기획 문서 3종 | 왜 이렇게 만들었나(9/2 기획서·견우 컨셉·캐릭터 프로토콜) |
| D | 표본 결과지 실물 2건 + 실측 검증 | 손님이 결제 후 실제로 받는 글의 수준 |
| E | 재회 레인 경쟁 실측 | 경쟁 5사가 이 카테고리에서 실제로 쓴 문장·구조 |

**⚠ 충돌하면 B가 이긴다.** C의 9/2 기획서는 화자가 「직녀」, 가격이 19,900으로 적혀 있는데 **낡았다.** 현행은 화자 **견우**, 가격 **29,900(정가 44,900)**이다. C는 의도를 읽는 용도로만 써라.

## 3. 표기 약속

- **[실측]** = 코드·문서·라이브에서 직접 확인한 사실
- **[추정]** = 구조에서 추론한 것 — 사실처럼 쓰지 마라
- **[외부]** = 경쟁사 조사에만 있고 우리 것이 아닌 것

당신도 제안할 때 이 표기를 쓴다. 근거 없는 단정은 쓰지 않는다.

## 4. 바꾸지 않는 것 (건드리면 상품이 깨진다)

1. **사주 계산·결제·데이터 구조.** 확정값(달·등급·연도·짝의 결)은 **코드가 계산한다.** 글은 그 값을 인용만 한다 — 새 계산·새 지표를 만들지 마라.
2. **견우 캐릭터 앵커 6개**(B-8): 잉크 남색 눈 + 은빛 별점 / 왼눈 바깥 밑 점 / 오른눈썹 흉터 / 왼손목 쪽빛 고삐끈 / 33세 성인 남성 / 기존 컷과 같은 사람.
3. **견우 말투**: 담백한 존댓말(~합니다/~요). 반말·사극 어미·느끼한 말·추파 금지. 손님을 "그대"라 부르지 않는다.
4. **직녀 세계의 물건을 견우가 쓰지 않는다**: 베틀·천·날실·씨실·무늬·실·**붉은 실** 금지. 견우의 그림은 강·은하수·다리·오작교·별·나루·장부·소·까치·등불이다.
5. **빨강·분홍 금지**(화면 전체).
6. **결과지 10장의 순서와 개수.** 제목 문구는 제안할 수 있으나, 바꾸자면 근거와 "같이 바꿔야 할 곳"을 함께 적어라(목차는 랜딩·티저·결과지가 1:1로 물려 있다 — 한 곳만 바꾸면 그 자리에서 들통난다).
7. **금지 문장**: 재혼 성공률 / 남편복·남자복 / 결혼 못 한다 / 팜므파탈 / 상대·새 인연의 직업·연봉·키·체형·이름 초성·사는 지역·학력 단정 / 상대를 1인칭으로 대신 말하기 / 겁주는 이별·파혼 서사.
8. **분량 앵커 금지**(A4 몇 장·몇 자·몇 분 읽기). 가짜 후기·지어낸 숫자 금지. 후기는 실제로 0건이다.
9. **가격·상품명**은 제안만 한다(결정권자가 따로 있다).
10. **카피는 쉬운 말.** 작가말·조어·비유 남발 금지. 이야기는 은유가 허용되지만 **상품을 말하는 순간부터는 직설**이다. 새 판매 카피는 **E에서 검증된 문장의 번안**을 우선한다.

## 5. 내놓을 것 — 문서 4종

승인 전에는 문서만 쓴다. 코드·이미지는 이쪽에서 만든다.

| 파일명 | 담을 것 |
|---|---|
| `storyboard_<날짜>.md` | ⓪ 서윤의 눈으로 현행 퍼널을 걸었을 때 **몰입이 깨지는 지점 5개**(B의 화면·문장을 근거로) + **구매자 3초 판정** 한 줄 ① 랜딩 → 티저 아홉 컷 → 결과지 인터루드의 컷별 그림·대사·나레이션. **있는 컷 재사용 / 새 컷 필요**를 반드시 구분 |
| `visual-bible_<날짜>.md` | 견우 표정·포즈·소품·배경의 방향(앵커 6 안에서) · 재회 세계관 그림 규칙(강·다리·등불·까치 서찰) · 금지 |
| `asset-list_<날짜>.md` | 새 컷 발주 리스트(id · 장면 한 줄 · 쓰이는 자리 · 우선순위) · 광고 영상 4종과의 연결. **영어 프롬프트는 쓰지 마라** — 발주 문장은 이쪽 조립기가 만든다 |
| `implementation-spec_<날짜>.md` | **화면별 문구 슬롯표(복붙용)**: 히어로 · 나레이션 · 위저드 6문항 라벨과 도움말 · 위로 화면 · 티저 웹툰부 7컷 대사 · T1~T5 · 잠금 문장 · 결과지 10장 머리 한마디 · 배웅 편지 틀 / 결과지 장별 「이 장이 남길 한 문장」 / 광고 훅 3~5개(E 번안) / **「화면 · 현재 → 변경」 표** / 리스크와 출구 / 역산표(유입→입력완료→티저완독→결제, 판정선 포함) |

## 6. 왕복 방식

- 답변 끝에는 **「지금 당신이 할 일」** 블록을 계속 붙여라.
- 이쪽 회신은 **네 줄 고정**으로 온다: `했다 / 못 했다(이유) / 실측이 다른 것 / 결정이 필요한 것`.
- 저장소 사실이 필요하면 물어라. 추측으로 채우지 마라.

## 7. 첫 답변에 할 일 (이것만. 새 대사·새 컷은 아직 쓰지 마라)

1. **인용 테스트** — 이 팩 **맨 끝 줄**을 토씨 그대로 옮겨 적어라(파일을 끝까지 읽었는지 확인용).
2. 이 상품을 한 문단으로 요약.
3. **서윤의 눈으로 현행 퍼널을 걸었을 때 몰입이 깨지는 지점 5개** — B의 화면·문장을 근거로.
4. E에서 스토리·대사·연출로 쓰고 싶은 재료 10개.
5. 팩만으로는 알 수 없어 물어야 할 것 목록.
