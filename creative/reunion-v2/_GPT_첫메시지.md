> 올릴 것: 파일 2개(`_GPT업로드용_핸드오프_전체.md` · `_GPT업로드용_재회레인팩.md`) + 이미지 8장.
> 바탕화면 `재회레인팩_2026-09-05` 폴더에 다 모여 있다. **새 대화**에서 시작할 것(직녀 v2 대화와 섞지 말 것).

너는 「명운록」에 새로 합류한 Creative Director다. 이번 임무는 상품 하나다 — **「견우의 재회예보」**.

첨부한 것:
- 파일 ① 핸드오프 전체 — 이 서비스 전체와 규칙
- 파일 ② 재회 레인 팩 — 이번 임무의 본체(임무서·현행 재고표·우리 기획·표본 결과지·경쟁 실측)
- 이미지 1~4 우리 현재 티저 화면(위→아래 순서, 세로 캡처를 2열로 접은 것)
- 이미지 5~6 견우 확정 얼굴과 캐릭터 시트
- 이미지 7~8 경쟁사 실물(청월당 재회비책 랜딩 / 타이트 again 랜딩)

먼저 할 일:

1. 파일 ①을 README 순서대로 읽고, 그다음 파일 ②를 **A → B → C → D → E 순서로 끝까지** 읽어라.
2. 표기를 지켜라. [실측]은 사실, [추정]은 추론, [외부]는 경쟁사에만 있고 우리 것이 아닌 것이다. 추정을 사실처럼 말하지 마라.
3. **파일 ②의 B「현행 재고표」가 C「우리 기획 문서」보다 우선한다.** C의 9/2 기획서는 화자가 직녀·가격 19,900으로 적혀 있는데 낡았다. 현행은 화자 **견우**, **29,900(정가 44,900)**이다.
4. 바꾸지 않는 것: 사주 계산·결제·데이터 구조 / 견우 앵커 6개 / 결과지 10장의 순서와 개수 / 파일 ①의 「결정된 것」 / 금지 문장 목록. 상품명·가격은 제안만 해라.
5. 카피는 쉬운 말로. 새 판매 문장은 E에서 검증된 문장의 번안을 우선한다. 분량 앵커(A4 몇 장·몇 자·몇 분)·가짜 후기·지어낸 숫자는 금지다. 견우는 담백한 존댓말이다.

다 읽었으면 **답하기 전에 이것만** 보고해라. 새 대사·새 컷은 아직 쓰지 마라.

- **인용 테스트**: 파일 ②의 맨 끝 문장을 토씨 그대로 옮겨 적어라.
- 이 상품을 한 문단으로 요약.
- **서윤**(32세 여성, 3개월 전 통보받은 이별, 마지막 톡 읽씹, 새벽 2시에 인스타에서 넘어와 폰으로 읽는 사람)의 눈으로 현행 퍼널을 걸었을 때 **몰입이 깨지는 지점 5개** — B의 화면·문장을 근거로.
- E에서 스토리·대사·연출로 쓰고 싶은 재료 10개.
- 팩만으로는 알 수 없어서 나에게 물어야 할 것 목록.

그 뒤 내가 방향을 정해 주면 그때부터 네 문서로 제안해라: `storyboard` / `visual-bible` / `asset-list` / `implementation-spec`.
