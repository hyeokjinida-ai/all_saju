## 1. 브랜드 전제 (이미 확정된 것에서 끌어옴 — 새로 정하지 않음)

- **이름의 무기는 「錄」.** 경쟁사는 전부 *장소*(청월堂·음양館·사주나루)거나 *사람*(도령·아씨). 우리는 *물건* = 기록·장부·책. 아무도 못 가진 모티프.
- **먹빛 단색 = 유일한 시각 차별화** (광고 소재 판독: 5사 전부 컬러). 로고도 **먹 1색 + 상아** 로 간다. 세계관 액센트(산군 금 / 직녀 은)는 이 1색만 바꿔 끼운다 → `currentColor`.
- **빨강 0.** 청월당 靑月堂印 붉은 인장 · 음양관 붉은 실 · 홍연아씨 — 붉은 도장을 쓰면 3번째가 된다. 인장을 쓰더라도 먹색.
- **한자는 장식만.** 워드마크 1순위는 한글 「명운록」. 「命運錄」은 세로 스택 보조줄에만.
- **「SAJU LAB」 영문 라벨 폐기.** (구 콘셉트 + 대문자 영문 라벨 = AI티)
- 타깃 3040 여성 · 유입 100% 메타 → 로고가 제일 많이 보이는 자리는 **광고 좌상단 40px 원**과 **카톡 인앱 탭 아이콘**이다. 큰 화면이 아니라 **작은 원에서 식별되는가**가 1번 판정선.

## 2. 방향 3안 + 판정표

| 판정선 | A. 사침 장부(錄) | B. 먹 인장(印) | C. 먹 한 점(點) |
|---|---|---|---|
| 16px 탭 아이콘에서 식별 | △ 네모 덩어리 (소형 변형으로 보완) | ✗ 글자 뭉개짐 | ◎ |
| 40px 광고 프로필 원 | ○ | △ | ○ |
| 먹/상아 양쪽 바탕 1색 성립 | ◎ | ◎ | ◎ |
| 산군·직녀 둘 위에 서는 우산 | ◎ 「기록」은 두 캐릭터의 공통 약속 | ○ | ○ |
| 경쟁 4사와 안 겹침 | ◎ 책 모티프 0곳 | ✗ 청월당 인장과 같은 원형 | △ 가장 일반형 |
| 이름과 결속 | ◎ 錄 직결 | ○ | △ 점(占) 말장난 |
| 이야기 확장(결과지·광고 스팅) | ◎ 장부 펼침/덮임 · **바늘땀 4 = 사주(四柱)** | ○ 도장 찍기 | △ |
| AI티 | ○ | △ 한자 장식 과다 | ○ |

**추천 = A 사침 장부.** 선장본(線裝本) 표지: 제첨(題簽) 표제지 + 등을 넘는 **바늘땀 4개(사침안정법 = 네 기둥)**.
B는 청월당 아류로 읽힐 위험이 크고, C는 깨끗하지만 아무 브랜드나 될 수 있다.
(A를 고르면 C의 먹 질감을 상아 인쇄판에만 빌려 쓴다. B의 인장은 결과지 말미 「기록 완료」 도장 부품으로 살릴 수 있음 — 로고는 아님.)

형님이 셋 다 아니면 **레퍼런스 1장**만 주시면 됨 — 「이거처럼」 1건이면 흡수표 1장으로 다시 그린다.

## 4. 제작 방식 — 그림은 생성 툴, 클로드는 기획·프롬프트·판정·벡터화·배선 (8/23 형님 정정)

> 초판은 「벡터를 코드로 직접 그린다」였다. 형님 판정(「너 디자인 못하는 거 알잖아」)으로 폐기 —
> 클로드가 손으로 그린 시안은 **판정 근거로도 쓰지 않는다**(저퀄 시안이 판정을 왜곡한다, 8/17 직녀 그림채 때와 같은 함정).
> `logo-directions.html` / `-sheet.png` 는 **방향 설명용 낙서**로만 남긴다.

- **생성 경로 2개 병행** → 프롬프트 팩 `로고_프롬프트_2026-08-23.md`
  - ① ChatGPT 웹 — 형님 붙여넣기(검증된 경로). 심볼 4방향 + 워드마크 2종 = 6프롬프트, 장당 2×2 그리드.
  - ② 힉스필드 — 클로드 실행. `recraft_v4_1`(`model_type: vector`, 팔레트 `#0E0E10`/배경 `#F3EAD6` 고정) 심볼 8장 + `nano_banana_pro` 워드마크 2장. 1차 상한 150크레딧, 첫 장 차감액 확인 후 진행. OpenAI API 계열(`gpt_image_2`·`openai_hazel`) 제외.
- **후보 보관** `design/brand/candidates/` → 클로드가 **쓰일 자리 크기 시트**(180·32·16·40px원·24px 헤더)로 재조립 → 형님 「이거」.
- **벡터화**(클로드): 1색 PNG → 배경 제거(threshold 또는 `image_background_remover`) → `vtracer`(pip) → SVG path 정리(구멍·계단 제거, 소형 변형 파생). 생성 원본은 2k로 다시 굽는다(그리드 셀은 저해상).
- **워드마크**: 생성 레터링(W1·W2) + **폰트 조판 보험 1종**(나눔명조 ExtraBold 아웃라인, fontTools). 24px 검정 헤더에서 나란히 놓고 고른다. 가평한석봉(청월당 헤드 글씨체)은 쓰지 않는다.
- 래스터(png/ico)는 헤드리스 크롬으로 굽는다 — 이 PC에서 검증된 명령:
  `"/c/Program Files/Google/Chrome/Application/chrome.exe" --headless=new --disable-gpu --hide-scrollbars --force-device-scale-factor=N --window-size=W,H --virtual-time-budget=6000 --user-data-dir=<scratch>/chrome-prof --screenshot=<out.png> file:///<html>`
- 먹/상아 값: 먹 `#0e0e10` · 상아 `#f3ead6`(산군 `--bone`). 토큰 새로 만들지 말고 `Logo.tsx`는 `currentColor`만.
