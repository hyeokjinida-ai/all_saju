# 메타 광고 라이브러리 전카테고리 스윕 키트

> 목적: 「사주」 하나만 보던 광고 라이브러리 조사를 **16 카테고리 · 135 키워드**로 넓혀, 소규모 광고주가
> **오래·많이** 돌리는(=돈이 되는) 카테고리와 착지 상품을 찾는다. 계획서: `메타광고_전카테고리_탐색_계획_2026-09-08.md`

## 왜 크롬에서 돌리나
- 광고 라이브러리는 API 가 정치 광고만 준다. 상업 광고는 웹 화면뿐이다.
- 원격 컨테이너(클로드 세션)에서는 facebook.com 이 망 정책으로 막혀 있다(2026-09-08 실측 403).
- 기존 3차 수집도 **실제 크롬**에서만 전량 로드됐다(내장 브라우저는 30건 고정 — `00_메타광고_업체랭킹.md`).

## 설치 (2분)
1. 크롬에 **Tampermonkey** 확장을 깐다.
2. Tampermonkey 대시보드 → `+`(새 스크립트) → 내용 전부 지우고 `scripts/adlib/dist/adlib-sweep.user.js` 를 통째로 붙여넣기 → 저장(Ctrl+S).
3. `https://www.facebook.com/ads/library/?country=KR&q=사주` 를 연다. 우하단에 **검은 패널**이 뜨면 설치 성공.
4. 크롬이 「이 사이트에서 여러 파일을 다운로드하도록 허용」을 물으면 **허용**. (키워드마다 JSON 을 한 개씩 내려받는다)

## 스모크 테스트 (5분, 반드시 먼저)
1. `q=사주` 페이지에서 패널의 **「1개만(현재 q)」** 클릭.
2. 다운로드된 `adlib_A_사주_<날짜>.json` 을 열어 확인한다:
   - `meta.cards` 가 300 이상인가 (8/23 실측 452장). 30 안팎이면 「더 보기」가 안 눌린 것 — 창을 앞으로 띄우고 다시.
   - `cards[0]` 에 `advertiser`·`start`·`reuse`·`hook` 이 채워졌는가. 비어 있으면 카드 DOM 이 바뀐 것 → 아래 「DOM 이 바뀌었을 때」.
3. `meta.emptyCards` 가 카드의 10% 이상이면 `cfg.tickMs` 를 1500 으로 올린다(Tampermonkey 편집기에서 DEFAULT_CFG).

## 전량 실행
1. 패널에서 tier 체크(기본 tier1 = 47개, 약 1~1.5시간) → **「▶ 시작/재개」**.
2. 스크립트가 키워드마다 페이지를 옮기며 **더 보기 → 파싱 → JSON 다운로드**를 반복한다. 창은 **앞에 띄워 둔다**(가려지면 렌더가 멈춘다).
3. 중간에 멈추면 「▶ 시작/재개」로 이어서 간다. 진행은 localStorage 에 있어 새로고침해도 유지된다.
4. 다 돌면 `adlib_요약_<날짜>.json` 이 내려온다. tier2·3 은 체크를 바꿔 다시 시작하면 **큐를 새로 만든다**(결과 파일은 남는다).

## 집계
```bash
mkdir -p ~/Downloads/adlib && mv ~/Downloads/adlib_*.json ~/Downloads/adlib/
node scripts/adlib/rank.mjs ~/Downloads/adlib --date 2026-09-09 --out 메타광고_전카테고리_보고서_2026-09-09.md
```
보고서 7개 표: 카테고리 랭킹 / 키워드 랭킹 / 광고주 / **착지(=돈 버는 상품)** / 위닝 훅 / 소규모 장기집행 키워드 / 수집 품질.
같은 이름의 `.json` 도 같이 나온다(다음 세션에서 클로드가 읽는 용도).

## 점수식
- market = 재집행합 30% + 장기집행(90일+) 수 30% + 광고주 수 15% + 소규모 광고주 비율 10% + 사이트 직행 비율 15% (키워드 간 백분위)
- score = market × (0.5 + 0.5 × 적합도). 적합도 = `keywords.json` 의 fit(build 제작난이도 · pg 결제심사 · reg 광고규제) 평균/3.
- **재집행 횟수가 핵심 지표**다(노출 순위는 예산이 만들고 재집행은 성과가 만든다 — `00_위닝소재_전체랭킹.md`).

## 함정 (기존 수집에서 확인된 것)
- 「더 보기」는 버튼이다. 무한스크롤이 아니다. 창이 가려지면 클릭이 안 먹는다.
- 카드 5% 안팎은 가상 스크롤로 본문이 비어 나온다(`empty:true`). 오차로 안고 간다.
- 착지 URL 은 `host+path` 만 저장한다. query 를 넣으면 보안 필터가 막는다.
- 속도 제한 문구가 뜨면 스크립트가 90초 쉬고 새로고침한다. 그래도 계속 막히면 30분 쉬었다 재개.
- 키워드 하나가 450장에서 잘리면(`truncated`) 상위 노출 450장만 본 것이다. 물량 상위 업체는 다 들어온다.

## DOM 이 바뀌었을 때
파서는 텍스트 기반이다: 카드 = 「라이브러리 ID: 숫자」를 정확히 1개 품은 가장 큰 조상. 광고주 = 「후원」 바로 윗줄.
게재 시작 = 「게재 시작일: 2026. 4. 15.」, 재집행 = 「광고 N개에서 이 크리에이티브 및 문구를 사용합니다」.
영어 UI 도 받는다(Library ID / Started running on / N ads use this creative). 문구가 바뀌면 `collector.user.template.js` 의 `RE_*` 만 고치고 `node scripts/adlib/build.mjs`.
