# 광고 라이브러리 수집 — 형님용 절차 v2 (확장 설치 없음, 복붙만)

> 2026-09-09 갱신 — 형님 지적 「키워드가 왜 이렇게 적어」 반영.
> **키워드 569개 (tier1 121 · tier2 299 · tier3 149) · 22 카테고리**로 늘렸다. 정본은 `keywords-v2.json`.
>
> 왜 형님이 해야 하나: 클로드 세션에서 `facebook.com` 이 **조직 망 정책으로 403**이다(2026-09-09 재실측). 우회하지 않는다.

---

## 방법 A — 배치 (권장, 알아서 다 돈다)

1. 크롬에서 광고 라이브러리 아무 검색 페이지를 연다.
   `https://www.facebook.com/ads/library/?country=KR&q=구독&active_status=active&ad_type=all`
2. **F12 → Console**. 처음이면 `allow pasting` 치고 Enter.
3. `scripts/adlib/batch-snippet.js` 를 열어 맨 위 **`KEYWORDS` 배열을 원하는 목록으로 바꾸고**, 파일 **전체**를 콘솔에 붙여넣는다.
4. 알아서 키워드를 하나씩 옮겨 다니며 긁고 **키워드마다 JSON 을 자동 다운로드**한다. 다 끝나면 요약 JSON 이 하나 더 떨어진다.
5. **창은 앞에 띄워 둔다.** 가리면 렌더가 멈춰 「더 보기」가 안 눌린다.

조작:
| 명령 | 하는 일 |
|---|---|
| `MUR.status()` | 진행 상황 표로 보기 |
| `MUR.stop()` | 정지 (다시 붙여넣으면 이어서 감) |
| `MUR.skip()` | 지금 키워드 건너뛰기 |
| `MUR.reset()` | 처음부터 다시 |

새로고침하거나 창을 닫았다 다시 붙여넣어도 **이어서 간다**(localStorage 에 진행 저장).

## 방법 B — 한 키워드만 (급할 때)

주소창 `q=` 만 바꾸고 `scripts/adlib/console-snippet.js` 를 붙여넣는다. 2분.

## 다 긁고 나서

받은 JSON 을 한 폴더에 모으고 **나한테 「수집 끝, 폴더 여기」** 라고만 주면 된다.
```bash
node scripts/adlib/rank.mjs <폴더> --out 보고서.md
```
나오는 것: 카테고리·키워드·광고주·**착지(=돈 버는 상품)**·위닝 훅 랭킹 + 「소규모 광고주가 90일 넘게 돌리는 키워드」 표.

## 함정
- **창을 앞에 띄워 둬라.** 가리면 「더 보기」가 안 눌린다.
- 카드 5퍼센트쯤은 본문이 비어 나온다(가상 스크롤). `empty:true` 로 표시되니 오차로 안고 간다.
- 한 키워드가 450장에서 잘리면 노출 상위 450장만 본 것이다. 물량 상위 업체는 다 들어온다.
- 「잠시 후 다시 시도」가 뜨면 배치가 알아서 120초 쉬고 새로고침한다. 그래도 계속이면 30분 쉰다.

## 검증
- 단건 스니펫: 모사 페이지 **13항목** 통과 (`node scripts/adlib/test/run-snippet.mjs`)
- 배치 스니펫: 모사 페이지 **7항목** 통과 (`node scripts/adlib/test/run-batch.mjs`)
- 둘 다 `playwright-core` 필요. **실제 DOM 은 확인 못 했다** — 첫 키워드에서 카드 수가 30 근처면 「더 보기」가 안 눌린 것이니 알려라.
