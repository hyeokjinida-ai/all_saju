# 광고 라이브러리 수집 — 형님용 절차 (확장 설치 없음, 복붙만)

> 왜 형님이 해야 하나: 클로드 세션에서 `facebook.com` 이 **조직 망 정책으로 403** 이다(2026-09-09 재실측).
> 우회는 안 한다. 형님 크롬에서만 긁을 수 있다.

## 1회만 하는 준비 (없음)
확장 설치 안 한다. 크롬만 있으면 된다.

## 한 키워드 긁기 (2분)

1. 크롬에서 아래 주소를 연다. **끝의 `전자책` 자리에 원하는 검색어**를 넣는다.
   ```
   https://www.facebook.com/ads/library/?active_status=active&ad_type=all&country=KR&media_type=all&q=전자책&search_type=keyword_unordered&sort_data[direction]=desc&sort_data[mode]=total_impressions
   ```
   > `sort_data` 두 개가 붙어 있어야 **노출수 순**으로 정렬된다. 이게 없으면 최신순이라 쓸모없다.

2. **F12** → 상단 탭 **Console**.
   (처음이면 "붙여넣기를 허용하려면 allow pasting 을 입력하세요" 가 뜬다. `allow pasting` 치고 Enter.)

3. 저장소의 `scripts/adlib/console-snippet.js` **파일 전체를 복사해서 콘솔에 붙여넣고 Enter.**

4. 알아서 「더 보기」를 반복해서 누르고 다 긁으면 **JSON 파일이 자동으로 다운로드**된다.
   - 콘솔에 `✔ 전자책: 312장` 처럼 결과가 찍힌다.
   - 표로 상위 10개 광고주·재집행·가격·착지가 미리 보인다.

5. 다른 키워드는 **주소창의 `q=` 만 바꾸고 3번을 다시** 하면 된다.

## 몇 개나 긁어야 하나

## 다 긁고 나서
받은 JSON 을 한 폴더에 모으고 **나한테 "수집 끝, 폴더는 여기" 라고만** 주면 된다. 내가 돌린다:
```bash
node scripts/adlib/rank.mjs <폴더> --out 보고서.md
```
나오는 것: 카테고리·키워드·광고주·**착지(=돈 버는 상품)**·위닝 훅 랭킹 + 「소규모 광고주가 90일 넘게 돌리는 키워드」 표.

## 함정
- **창을 앞에 띄워 둬라.** 다른 창에 가리면 렌더가 멈춰서 「더 보기」가 안 눌린다.
- 카드 5% 정도는 본문이 비어 나온다(가상 스크롤). `empty:true` 로 표시되니 오차로 안고 간다.
- 한 키워드가 450장에서 잘리면 노출 상위 450장만 본 것이다. 물량 상위 업체는 다 들어온다.
- 「잠시 후 다시 시도」가 뜨면 30분 쉬었다 한다.

## 검증
파서는 모사 페이지로 13항목 통과했다: `node scripts/adlib/test/run-snippet.mjs` (playwright-core 필요).
실제 DOM 은 확인 못 했다 — **첫 키워드에서 카드 수가 30 근처면 「더 보기」가 안 눌린 것**이니 나한테 알려라.
