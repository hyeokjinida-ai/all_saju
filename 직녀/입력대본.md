# 직녀 대화형 입력 — 화면별 대사 전문

## 0. 왜 이렇게 만드나 (구현자가 먼저 볼 것)

시장 1위(재집행 102회)가 입력에서 하는 것 세 가지를 그대로 가져온다.

| # | 장치 | 효과 |
|---|---|---|
| 44 | **캐릭터를 배경에 블러로 세워두고** 한 항목씩 묻는다 | 폼 화면으로 넘어가지 않아 이탈이 준다 |
| 44 | **「다음」 버튼 없이 자릿수가 차면 자동 진행** | 마찰 0 |
| 46 | **마지막 자유 고민 화면에서만 블러가 풀린다** | 「이제 진짜 듣는다」 연출 |
| 45 | **결과 보기 직전에 이메일**을 캐릭터 대사로 받는다 | 리드 확보 지점 |

**우리 유리한 점**: 산군 위저드(`SajuWizard`, 1/10~10/10)가 이미 같은 문항 구성으로 돈다.
**문항은 그대로 두고 대사만 직녀 보이스로 갈아 끼운다** — 엔진을 포크하지 않는다.

## 1. 보이스 규칙

- **직녀는 해요체 존대.** 재촉하지 않지만 **달은 반드시 못 박는다.**
- **버튼(손님 대사)은 반말.** 양쪽 다 존대면 위계가 0이라 손님이 을이 된다 → 손님을 위로 올린다.
- 베틀 비유는 **한 화면에 한 번**을 넘기지 않는다.
- 산군을 「산군님」이라 부르며 존대한다.

### 로딩 — 계산 체크리스트
> 대기를 「기다림」이 아니라 **「계산이 돌아가는 증거」**로 바꾼다.

```
        ☯   ○○님의 천을 짜는 중이에요

   「날실을 거는 중이에요…」
   → 「씨실이 지나간 자리를 세는 중이에요…」
   → 「무늬가 도는 달을 달력에 매는 중이에요…」        (순환)

   ✓  사주 원국 여덟 글자 세우기
   ✓  천간·지지의 충·합·형 분석
   ✓  대운 시작 나이 계산 (절입일 기준)      ← 우리만 검증한 항목
   ⋯  세운·월운 36개월 전개
   ⋯  배우자궁 판정
```
★ ✓가 하나씩 켜진다. 4번째 줄이 티저 Q&A의 검증 영상으로 이어진다.

## 3. 구현 메모

- **자동 진행**: 생년월일 8자리·시각 4자리가 차는 순간 다음 화면. 「다음」 버튼을 두지 않는다.
- **배경**: 8단계 내내 캐릭터 일러를 `filter: blur(8px)` 로 깔아 둔다. 8/9에서만 0으로 푼다.
- **뒤로**: 좌상단 `‹` 한 개. 확인 화면에서 각 항목 옆 「고칠게」.
- **진행 표시**: `1/9` 형식. 산군과 같은 자리.
- **입력값 세팅**은 React 네이티브 setter로 — `value=` 직접 대입은 무시된다.
- 이메일 화면 이탈 시에도 **앞 8단계 값은 세션에 남긴다**(다시 들어오면 이어서).
