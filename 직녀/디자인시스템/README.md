# 직녀 밤 계열 디자인 시스템 v1 (2026-08-22)

청월당 한 곳을 색만 바꿔 따라 쓰던 것을 그만두고, **부품을 여러 집에서 실측해 오되
표면을 전부 우리 것으로 바꿔** 출처를 지운 결과물. 티저 전체 **28,625px**.

> 방법론 원문은 `docs-private/직녀_디자인/레퍼런스_복제_작업법.md`.
> 이 폴더는 그 방법으로 만든 **직녀 실물**이다.

---

## 왜 방향을 바꿨나

지금까지의 4컷은 「밝은 파스텔 + 카드 조판」 = **청월당 영토**였다. 색만 보라로 칠한 상태라
청월당 손님이 보면 같은 템플릿으로 읽힌다. 그리고 우리 에셋(j1·j3·웹툰컷)이 전부 밤이라
밝은 바탕에서는 매 컷 `brightness(1.42)` 보정을 걸어야 했다 — 배경이 캐릭터와 싸운다는 신호.

**청월당에서 가져갈 것은 「밝음」이 아니라 「밝기 리듬과 정점」이었다.**
그래서 방향을 뒤집었다: **바탕은 밤, 정보 판만 달빛으로 띄운다.**
「밤하늘에 뜬 예보」 — 이건 청월당 것도 타이트 것도 아니다.

## 부품 구성

각 컷이 어떤 레퍼런스를 실측해 만들어졌고 표면을 어떻게 치환했는지는
**`docs-private/직녀_디자인/디자인시스템_출처표.md`** 에 있다(공개 리포라 여기 두지 않는다).
같은 폴더에 실측 대조 노트와 렌더 PNG 전량이 있다.

## 파일

```
tokens.css      ★ 색·타이포 눈금·여백·형태·그림자. 여기 없는 값을 컷에 직접 쓰지 않는다
01_상단.html    히어로 → 고민버블 → 예보판 → 원국 증거   (6,658px)
02_목차.html    분량 증명 (10장 전량)                    (8,370px)
03_대조.html    타사 3문제 → 우리 3강점                  (7,703px)
04_VS.html      시세 4종 vs 17,900                       (2,683px)
05_가격카드.html 구매                                    (3,211px)
tools/          shoot · lines · measure · compare · cutout
```

렌더: `powershell -File tools/shoot.ps1 -Html 01_상단.html -Out out.png -H 6658`
(폰트는 작업 폴더 `fonts/` 필요 — 받는 법은 `docs-private/직녀_디자인/실측_대조노트.md`)
렌더 PNG 전량도 같은 docs-private 폴더에 있다.

## 설득 순서 (청월당과 다르게 짠 것)

```
설화 히어로 → 손님 고민 → 개인화 예보(12칸) → 만세력 증거 → 분량 → 타사 대조 → 값 → 구매
```

청월당은 가격을 중반에 한 번 더 치지만, 우리는 **증거를 앞으로 당겼다.**
청월당 POINT 가 "폭넓은 명리이론 적용" 같은 **주장**인 반면 우리는 실제로 계산하므로
원국표 실물을 보여준다 — 남이 못 베끼는 컷은 이렇게 만든다.

## 지켜야 할 규칙

1. **토큰 밖 값 금지.** 필요하면 `tokens.css` 에 먼저 추가하고 쓴다(짜깁기가 또 다른 밤티다).
2. **컷마다 정점 한 줄.** 그 줄만 주변의 1.5~2배 + 색, 나머지는 400 으로 받친다.
3. **글·사진 교차.** 글 블록 두 개를 연달아 쌓지 않는다(목차의 SD 말풍선이 그 장치).
4. **강조는 형광펜(반투명 띠) + 글자색.** 박스로 가두면 글자가 눌린다.
5. 밤 위 본문은 은사(`--silver`), 판 위 본문은 `--b-md`. 대비 확보 후 분위기.
