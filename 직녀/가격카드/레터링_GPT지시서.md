# 「연애예보」 레터링 — GPT 웹에서 뽑는 법

## 형님이 하실 일 (5분)

1. ChatGPT 웹 열고 **`연애예보_레터링원본.png` 를 업로드**
2. 아래 A안 프롬프트를 그대로 붙여넣기 → 나온 그림 저장
3. B안도 같은 방식으로 한 번 → 저장
4. 마음에 안 들면 "한 번 더" 정도만 치고 3~5장 모으기
5. 모은 파일을 **바탕화면에 그대로** 두시면 제가 누끼 따서 카드에 얹고 대조 시트 만들어 드립니다

> ⚠ **글자를 텍스트로 시켜 새로 그리게 하지 않습니다.** 그러면 「예」가 「얘」가 되는 식으로 획이 틀어집니다.
> 반드시 **이미지를 업로드하고 "이 모양 그대로, 표면만 바꿔라"** 로 시켜야 합니다.
> 원본에 글로우·그림자를 일부러 안 넣었습니다 — 그건 제가 코드로 얹는 게 훨씬 깨끗하고, 누끼도 쉬워집니다.

## A안 — 입체 유리 (청월당식 · 추천)

```
업로드한 이미지의 한글 글자 「연애예보」의 획 모양과 글자 비율을 정확히 그대로 유지해 주세요.
글자 형태는 절대 바꾸지 말고, 표면 질감만 다음처럼 바꿔 주세요.

- 두꺼운 아크릴 블록처럼 입체로. 위쪽 모서리에 밝은 하이라이트, 아래쪽으로 갈수록 깊은 색
- 색은 보라 계열 유지: 밝은 라벤더에서 깊은 자주로 떨어지는 그라데이션
- 표면에 유리 같은 광택 반사를 사선으로 한 줄
- 글자 테두리는 밝은 라벤더로 얇게 유지

반드시 지켜 주세요:
- 배경은 순백색(#FFFFFF) 단색으로 완전히 평평하게. 그라데이션·질감·무늬·패턴 전부 금지
- 글자 바깥으로 빛번짐(glow)·그림자·후광을 만들지 마세요. 배경은 깨끗한 흰색만
- 글자는 정확히 네 글자. 새 글자나 획을 추가하지 마세요
- 가로로 넓은 구도, 글자가 화면을 꽉 채우게
```
