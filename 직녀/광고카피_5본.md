## ① 「내게 올 사람」 — 1번 훅 · 9초형

```
[상단 2줄 고정 — 9초 내내 안 내린다]
        내게 올 사람,
        먼저 보고 갈래요?

0.0–3.6   J3 베틀 방 → J2 짜다 만 천 → J1 정면      ← 훅 그대로 3컷
3.6–6.6   ★ 결과지 「내게 올 사람」 카드 실물
          「늦게 데워지는 화롯불형」 + 5지표 + 블러 사진

7.6–9.0   [ 무료로 천 펴보기 ]
```

```

```

## ② 「무늬력」 — 자체 지표 (#78)

타이트는 「여우력」, 용용은 「1점」을 만들어 팝니다. **숫자를 크게 박습니다**(8/14).

```
[상단 2줄]
        내 무늬력
        ██점

0.0–3.0   J1 + 큰 숫자 카운트업 (0 → 68)
3.0–6.0   ★ 결과지 「인연 그릇 68점」 + 계산 근거 3줄
6.0–8.0   「이 점수가 어디서 나왔는지도 같이 드려요」
8.0–9.0   [ 내 무늬력 보기 ]
```
**본문 훅**
```
내 무늬력 몇 점일까?
점수만 던지지 않고, 그 점수가 나온 자리까지 같이 봐요.
```
> ⚠ 「무늬력」은 **인연 그릇 점수**의 다른 이름입니다. 결과지 1장의 값과 반드시 같아야 합니다.

## ③ 낮은 점수를 소재로 (#79)

용용사주가 「점수 1점 나왔셍..!!」을 광고로 돌립니다. **낮은 점수가 더 잘 돕니다.**

```
[상단 3줄]
        무늬력 23점 나왔는데
        직녀가 한 말이
        좀 이상해서요

0–5s    낮은 점수 화면 (23점)
5–12s   ★ 결과지 본문 스크롤
        「점수가 낮은 건 인연이 없다는 뜻이 아니에요.
         날실이 눌린 구간이라, 지나가면 열려요.」
12–17s  「눌린 구간이 언제 끝나는지도 적혀 있었어요」
17–20s  [ 내 점수 보기 ]
```
> 낮은 점수를 **겁이 아니라 해석**으로 받는 게 이 소재의 전부입니다. 죄책감 해제(B3-3)와 같은 논리.

## ④ 3자 관점 (#80)

「친구 썸남이 너무 쎄하게 생겼을때 특」 — **본인이 아니라 남을 봐준다**는 프레임은 진입 장벽이 낮습니다.

```
[상단 2줄]
        친구가 소개해 준 사람이
        자꾸 걸릴 때

0–6s    카페 2인 대화 톤 자막
        「야 이 사람 어때」 / 「사주부터 보자」
6–14s   ★ 결과지 「거를 사람」 카드 — 블러 + 태그
        「무늬인 척 섞인 잡실」
14–18s  「거를 사람도 같이 알려주더라」
18–20s  [ 친구 것부터 보기 ]
```

## ⑤ 목차 자체를 소재로 (#82)

「보기만해도 흥미로운 목차❤️」 + 목차 카드. **분량이 그림으로 보이는** 소재입니다.

```
        열 장짜리 인연 풀이

0–4s    목차 카드 1 (1~4장)
4–8s    목차 카드 2 (5~7장)
8–12s   목차 카드 3 (8~10장)
12–16s  「+ 8,000자」 배지 크게
16–20s  [ 목차 전부 보기 ]
```

## 판정선

| 상황 | 판정 |
|---|---|
| 30만 소진 · ROAS < 0.8 | 상단 훅 2줄만 교체 |
| **ROAS 1.5+** | **위닝 → 광고 6~10개로 복제해 물량**(#74). 새로 찍지 않는다 |
| CTR < 0.6% | 첫 3컷(훅 구간) 교체 |
| 클릭은 나오는데 CVR < 0.5% | 소재 아님 → 티저 결함 |
