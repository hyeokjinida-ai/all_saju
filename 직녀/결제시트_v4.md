# 직녀 결제시트 v4

## 0. ⚠ 현행 배선 (지금 코드에 살아 있는 값)

**이 문서의 3단 카드는 아직 구현이 아닙니다.** 지금 결제시트는 이렇게 돕니다:

| slug | 판매가 | 정가 | 상태 |
|---|---:|---:|---|
| `inyeon-saju` | **17,900** | 24,900 | 활성 |
| `sangun-sinjeom` | 19,900 | 29,900 | 활성 |
| `bundle-sangun-inyeon` | **26,900** | 54,800 | 활성 (=29,900+24,900) |

⚠ 구성품 정가를 바꾸면 번들 정가(54,800)도 같이 바꿔야 화면 산수가 안 깨집니다.

## 1. 3단 카드 문구 (R5 승인 시)

청월당은 **분량**을 묶고 타이트는 **다른 캐릭터**를 묶습니다. 직녀는 캐릭터가 하나뿐이라
**청월당식(분량 번들)** 으로 갑니다. 2호 캐릭터(재회)가 나오면 크로스셀로 전환합니다.

```
┌──────────────────────────────────────────────────────┐
│  총 ██,███원 아끼셨어요                                │
│                                                      │
│  받는 것                                              │
│ ┌──────────────────────────────────────────────────┐ │
│ │ 인연 들어오는 달              40%  3̶3̶,̶0̶0̶0̶  19,900 │ │ ← 기본 선택
│ │   열두 달 전부 · 내게 올 사람 · 거를 사람            │ │
│ ├──────────────────────────────────────────────────┤ │
│ │ 직녀의 천 한 폭        [추천] 42%  5̶2̶,̶0̶0̶0̶  29,900 │ │
│ │   위 전부 + 산군의 운명 장부(11장)                  │ │
│ ├──────────────────────────────────────────────────┤ │
│ │ 천과 장부, 그리고 물음  [추천] 44%  8̶9̶,̶0̶0̶0̶  49,900 │ │
│ │   위 전부 + 따로 묻고 싶은 것 3번                   │ │
│ └──────────────────────────────────────────────────┘ │
│                                                      │
│  상품값            33,000                             │
│  지금 치르면       -13,100                            │
│  [ 쿠폰 확인 ]                                        │
│                                                      │
│           [    실값 치르기    ]                       │
│                                                      │
│  ☑ 소식 받기 (선택)                    자세히 보기     │
└──────────────────────────────────────────────────────┘
```

**할인율 역전**(40% → 42% → 44%)이 이 시트의 일입니다 — 단품만 사면 손해처럼 보이게 만듭니다.

## 2. 「실값」 — 결제라는 단어를 쓰지 않는다

시장 1위는 티저에서 「결제」를 **한 번도** 안 씁니다. 전부 「복채」입니다.
직녀는 베 짜는 사람이라 **「실값」**이 자연스럽습니다(은사와도 붙습니다).

| 자리 | 쓰지 말 것 | 쓸 것 |
|---|---|---|
| 버튼 | 결제하기 | **실값 치르기** |
| 티저 잠금 | 결제하시면 | **실값을 치르시면** |
| 영수증 | 결제 완료 | **실값 받았어요** |
| 환불 | 결제 취소 | **실값 돌려드려요** |
| 잠금 안내 | — | **여기까지만 짰어요. 나머지 무늬는 북을 더 움직여야 나와요.** |

⚠ 단, **법정 고지·영수증·약관·PG 화면은 「결제」 그대로** 둡니다. 세계관보다 법이 위입니다.

## 3. 쿠폰 = 로그인 미끼 (#49)

시장 1위는 쿠폰이 있는지 없는지도 **안 알려주고** 로그인만 시킵니다.
카카오 채널 친구 57,407명이 여기서 나왔습니다. 결제 직전이 로그인 전환이 가장 잘 되는 순간입니다.

```
[ 쿠폰 확인 ]  누르면 →

   ┌────────────────────────────────┐
   │  쿠폰함  0장                 ✕  │
   │                                │
   │      로그인하고                 │
   │      쿠폰이 있는지 확인해 보세요  │
   │                                │
   │    [ 💬 카카오로 확인하기 ]      │
   └────────────────────────────────┘
```
- 비로그인: 위 화면
- 로그인: 보유 쿠폰 목록(없으면 「지금은 쿠폰이 없어요」)
- **「소식 받기」는 기본 체크** (1위도 그렇게 합니다)

## 4. 상태별 분기

| 상태 | 화면 |
|---|---|
| 비로그인 | 3단 카드 + 「쿠폰 확인」 → 카카오 유도 |
| 로그인·쿠폰 있음 | 쿠폰 자동 적용 + 「○○님 쿠폰 적용했어요」 |
| 로그인·쿠폰 없음 | 「지금은 쿠폰이 없어요」 (닫으면 원래 가격) |
| 산군 기구매자 | ②③번 카드에서 산군을 빼고 차액만 — **이미 산 걸 또 팔지 않는다** |
| 번들 선택 | 결과지 2개가 각각 생성됨을 한 줄로 고지 |

```
   · 몇 분 안에 이 화면에서 열려요
```
